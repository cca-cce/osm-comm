# Project Context
This is an open science methods project for communication science education with course materials for multiple classes.

# Development Commands
- No build process (static HTML files)
- No test suite currently configured
- No linting/formatting tools configured

# Project Structure
- `web/edu/` - HTML lecture materials and workshops
- `jnb/` - Jupyter notebooks 
- `csv/` - Data files and datasets
- `res/` - Resources including educational images and models
- `fig/` - Figures and diagrams

# Course Information
- skoc62: Workshops 1-4
- simp59: Data transformation and visualization lectures  
- simm71: NLP and computer vision labs (external Colab links)
- scom: Various communication science courses

# File Naming Conventions
- Course materials use prefixes like `skoc26-`, `simp59-`, etc.
- HTML files for web delivery in `web/edu/`
- Screenshots and educational images in `res/edu/`
